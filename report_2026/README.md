# Phase II / Phase III ORR manuscript

Publication draft analysing objective response rate (ORR) in contemporary
Phase II/III oncology trials: combination interactions under a Bliss-independence
null, and the predictive value of Phase II ORR for Phase III. Styled after
Kang, DiPaola & Vázquez (BMC Med Res Methodol 2013;13:77) and
Azam & Vázquez (Cancers 2021;13:178).

## Build

```
make            # -> manuscript.pdf (needs a TeX distribution)
# or:
pdflatex manuscript.tex
```

## Files
- `manuscript.tex` — the paper (self-contained; embedded bibliography)
- `figures/agreement_scatter.png` — Phase II vs Phase III ORR
- `figures/bland_altman.png` — Bland–Altman agreement

Numbers are generated by the `phase2` analysis pipeline (post-2020
ClinicalTrials.gov cohort). Author/affiliation lines are placeholders to edit.
